On 19 October 2026 the owner explicitly selected the rebuilt SQLite source and authorized migration and removal of obsolete PostgreSQL data. replace_current_postgres.py first inventoried the dedicated schema and checked for foreign-key dependencies from other schemas. It saved the previous data to a private ignored backend/.legacy-backups JSON, then replaced only the known CRM tables in one transaction. Twelve retired CRM tables were removed; ten current tables remain. No other schema was modified. After live PostgreSQL validation, the local SQLite source and nine earlier demo/test/backup databases were removed.
