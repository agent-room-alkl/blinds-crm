结论不来自转述别人的验收记录。证据分三级，每条都标注：

## 一、总体结论

核心订单主线**已实现并经我实测**。几个最容易糊弄的环节都没糊弄：审核前不开票、收款前不放行供应商下单、超量交付被拒、跨公司不能合并开票、到货不覆盖收款状态。

未完成的功能**只有一类**：需要客户补规则或数据的（见第三节）。按 v5 基线，**没有一项是「该做而没做」**。

### D. 待客户决策（非缺陷）

**产品可订范围**。官网 5 个系列；模板 23 个条目。我核对过二者不是同一回事：

```
Shutters_PVC / PVC_Eco / Pinewood / Basswood   kind=shutter  面积计价   ← 官网 4 个
Shutters_Aluminium                             kind=shutter  面积计价   ← 同族，官网未展示
Roller/Venetian/Vertical/Exterior Blinds (18)  kind=blind    宽×高矩阵  ← 另一类产品
VERA_Ashwood_display                           展示用，无价格           ← 官网第 5 个
```

**这 18 个不是 5 个 shutters 的配置项**：计价引擎不同（面积 vs 二维矩阵）、配置字段不同（叶片/layout/VT post vs 底轨/链条/bracket 颜色）、本来就是不同品类。若按「配置出来的」处理，卷帘会被套上面积公式，报价会错且不易察觉。

选项：(甲) 可订范围 = 官网 5 系列，停掉 18 个 blinds；(乙) 维持现状（官网展示 5，登录后可订 23）；(丙) 官网补齐 18 个品类介绍。已交 Robin 决定，**未改动任何产品数据**。
