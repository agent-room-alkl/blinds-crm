# VERA 客户邮件与现用模板调整核对

日期：2026-10-16。来源：房间中客户回复截图、仓库根现用 xlsm，以及待 Grok 独立核对的官网产品资料。以下区分已核实的事实和下一步建议。

## 先调整的结论

1. 定金改为 **60%**。客户邮件明确纠正旧方案的20%；新建定金草稿已采用60%并保存比例/舍入/来源快照。历史已生成账单不回写。客户回复认可大体功能清单，并要求先出框架再查漏补缺，不等于所有细节、价格算法和开发验收都已确定。
2. 产品结构改为官网产品类别/产品内容 + Excel可订购配置条目。Excel有23个产品条目，不应继续用3个示例材质代替，也不能把23个条目直接说成23个库存SKU。官网介绍与Excel内部代码需要逐项映射。
3. 计价不能继续假设所有产品都是面积单价。现用表对 shutters 用面积，对其他 blinds 用宽高二维矩阵；安装、折扣、GST、手工附加项及舍入分别计算。现有通用面积引擎还不能当作真实价表已经接通。
4. 明细表单要随产品类别变化；Panel Q'ty 与同配置窗户数量需要区分，不能默认为同一字段。
5. Excel是客户当前业务模板，不能未经核实就把它当成工厂原始模板。保留客户订单、批发报价、Blinds Order、Shutter Order、Job Sheet不同输出角色；确认哪一份才是供应商实际接收格式。
6. 不照搬历史残留：工作簿同时含50%与60%定金块、有空白输出页及错误缓存。按客户最新确认取60%，其余冲突列清单确认，不能自动把旧值导入生产系统。

### 字段映射

- `In Put!A4:T4`：订单号、公司、联系人、电话、邮箱、地址、报价日期、转介、销售、商品合计、安装、GST、总价、定金、尾款、状态、类型、确认日期、预计交期、动作。地址需继续区分公司地址和具体项目地址，不能因Excel单地址标签就合并。
- `Order!A6:Q7`：公共窗户位置、宽(mm)、drop(mm)、产品、panel数量、内/外/成品尺寸、特殊要求。
- Blinds字段包括控制侧、支架颜色、链颜色、主色、底轨颜色。
- Shutters字段包括layout code、VT post、HT post、midrail、frame、louver size、colour、control rod。
- `Order!R6:U6`：折扣、最终价格、商品附加费、安装附加费。不能全映射为一个人工unit_price。
- `Order!E8:E36`验证引用命名区域Product；L/M/N/O列通过INDIRECT随产品切换选项，P列引用Fitting。应做产品配置schema与联动，不能给所有系列同一组选项。

### 计算证据与实现影响

|证据位置|当前公式表达的规则|系统需要处理|
|---|---|---|
|Order!V8|shutters面积=MAX(ROUNDUP(width×drop/1000000,2),0.5)；其他为1|面积先向上保留2位、最低0.5m²；不能用“尺寸进位”假装相同|
|Order!W8|shutters面积×Pricing!A485:B489产品单价+商品附加费；其他按命名宽/高矩阵嵌套XLOOKUP match_mode=1+附加费|至少支持area/matrix两类计价，矩阵上档匹配、越界拒绝；不能把查不到时0元当成功价格|
|Order!S8|ROUNDUP(W8×(1-R8),2)|折扣和向上舍入顺序须保持；样例核对不同于默认ROUND_HALF_UP|
|Order!X8|安装选择开时，shutters按panel数×对应安装费+附加费；其他按产品安装费+附加费，再ROUNDUP(...,2)|panel数量与订单数量区分；安装选择/附加费分开|
|In Put!Q31:Q34|商品合计；若安装开启总安装费最低150；(商品+安装)×0.15为GST；再合并总价|订单级最低安装费、GST和行价分层；0.15来自客户工作簿，不是外部税务判断|
|In Put!P49/P51|总价=SUM(P46:P48)；60%定金=ROUNDUP(P49×0.6,2)|目前修订按此60%块实现新定金；保留来源和快照|
|In Put!P36/Q36|另一块仍为0.5，Q34×P36|与新邮件冲突；标为旧残留，不能自动导为50%|

有些公式使用IFERROR(...,0)，另有_xleta隐藏名称引用#NAME?。需要分别核对实际Excel版本兼容性、宏依赖及异常尺寸，不能以缓存金额证明工作簿现在可正确重算。当前未改原xlsm，也没有宣称完成VBA迁移。

## 建议下一轮执行顺序

1. **内容与目录**：官网抓取真实类别/产品介绍，映射Excel23个代码，保留可订购/仅展示标志；未确认的产品不编造中文材料名、图片授权或价表。
2. **字段原型**：以Blinds/Shutters分表单，核对panel数量、layout与post、控制、颜色、安装及内外装；确认员工专用附加费与客户可填选项。
3. **计算移植**：将两种引擎、面积/金额ROUNDUP、订单最低安装费、折扣/GST拆为可版本化规则。至少取一条shutter、一条roller矩阵、一条安装、边界与异常尺寸，逐行对账后再开放真实报价。
4. **输出模板**：先确认客户实际使用哪个输出表与供应商收单格式，确定宏承担的复制/筛选/版式动作；再做可下载Excel，不直接重建一个外形相似文件。
5. **订单运营**：沿用已做公司隔离、审核、60%定金、人工收款、批量在途/数量到货/通知。尾款用实际已收定金，不硬算旧20%；部分到货分摊及返利自动公式仍待规则。

## 仍需客户补充的具体问题

- 邮件60%已明确，不再反复问比例；确认其是否适用所有客户、何时起生效，以及旧订单如何保留。
- 23个模板条目哪些仍对外销售，官网产品是否全部支持批发订购？
- Panel Q'ty是扇数/面板数还是同窗数量？复制同配置窗户应怎样计价？
- 两套定金输出和空白Shutter Order的现行使用方式是什么？实际发送给供应商哪一张表？
- 价格矩阵和手工附加费是否最新，折扣谁可修改，价格生效与锁价节点是什么？
- 一组真实脱敏正确结果，涵盖shutters、矩阵blinds、安装、边界与异常情况。
- 部分到货时定金分摊/尾款开票、月度返利基数阶梯及撤销更正仍没有被这封邮件补齐。
